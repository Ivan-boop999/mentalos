# MentalOS v3.0 — План полного функционала (по анализу рынка)

## Источники анализа
Zapier, 2sync, HabitBox, Habi.app, Mindful Suite, Loop, Habitica, Productive, Fabulous, Streaks, Done, Atomic Habits, Reddit r/productivity

## 🎯 Категории функций

### TIER 1: CORE (база — должно быть в любом трекере)
- [x] Создание/редактирование/удаление привычек
- [x] Ежедневные отметки
- [x] Streak (текущая серия)
- [x] Best streak (рекорд)
- [x] Напоминания (по времени)
- [x] Категории
- [x] Дизайн (светлая/тёмная)
- [ ] **SKIP DAYS** — отметка «пропустить» (не портит streak, как в Streaks/Loop)
- [ ] **FLEXIBLE FREQUENCY** — X раз в неделю (не только по конкретным дням)
- [ ] **GOAL TYPES** — measurable (количественные цели): «выпить 2л воды», «прочитать 30 мин»
- [ ] **NOTES per check-in** — заметка к отметке (как в Productive)
- [ ] **SUB-TASKS / CHECKLIST** — чек-лист внутри привычки

### TIER 2: PROGRESS & ANALYTICS (глубокая аналитика)
- [x] Календарь-месяц (GitHub-grid)
- [x] Статистика за 7/14/30 дней
- [x] Графики (Recharts)
- [x] Completion rate %
- [ ] **HABIT STRENGTH SCORE** (как Loop — взвешенная сила привычки)
- [ ] **PERFECT DAYS** (дни, когда всё выполнено — как Productive)
- [ ] **ГОДОВАЯ статистика** (52 недели heatmap как GitHub contribution)
- [ ] **Прогноз/тренд** (растёт ли регулярность)

### TIER 3: MOTIVATION & GAMIFICATION (мотивация)
- [x] Достижения (7/30/100 дней)
- [x] Бонусы и реферальная программа
- [x] Конфетти при 100%
- [ ] **CHALLENGES** (челленджи — 30 дней воды/медитации и т.д.)
- [ ] **УРОВНИ И XP** (как Habitica — рост уровня)
- [ ] **БОЛЬШЕ достижений** (первая отметка, 50 привычек, 365 дней, etc.)
- [ ] **МОТИВИРУЮЩИЕ ЦИТАТЫ** дня

### TIER 4: WELLBEING (благополучие)
- [ ] **MOOD TRACKING** (настроение дня: 😊😐😢 + заметка)
- [ ] **JOURNAL/DIARY** (дневник благодарностей/рефлексии)
- [ ] **HABIT TEMPLATES** (готовые шаблоны: «Здоровье», «Учёба», «Спорт»)

### TIER 5: UX (пользовательский опыт)

- [x] Календарь

- [ ] **EXPИРТ данных** (JSON/CSV — как Loop)
- [ ] **ТЕМЫ оформления** (покупаемые в магазине — активировать!)

### TIER 6: SOCIAL (социальность)
- [x] Реферальная программа
- [ ] **Поделиться прогрессом** (картинка в сторис — есть, улучшить)

## 🎨 Дизайн-принципы (UX best practices)
1. **3-секундный check-in** — отметка за 3 касания (HabitBox)
2. **Dopamine hit** — мгновенная визуальная награда (Habi.app)
3. **Минимум кликов** для настройки (Medium UX study)
4. **Цветовая кодировка** yes/no/skip (видно тренды сразу)
5. **Виджеты и dashboard** (Facebook UX community)
6. **Pulled-from-Telegram** native feel

## ПРИОРИТЕТ РЕАЛИЗАЦИИ
P0 (обязательно): skip days, measurable goals, notes, mood, challenges, perfect days, onboarding, темы активируются
P1 (важно): XP/уровни, годовой heatmap, экспорт, поиск, шаблоны, больше достижений, цитаты
P2 (nice-to-have): чек-листы, journal, leaderboard
