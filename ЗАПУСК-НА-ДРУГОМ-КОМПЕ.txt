============================================================
  MentalOS — запуск на другом компьютере
============================================================

ЧТО ВНУТРИ АРХИВА:
- client/   — фронтенд (React + Vite)
- server/   — бэкенд (Node.js + Express + Telegram бот)
- .env.example — шаблон переменных окружения
- README.md — полная документация проекта


ШАГ 1. УСТАНОВИТЬ ПРОГРАММЫ (один раз)
------------------------------------------------------------
1. Node.js 22+    → https://nodejs.org  (скачай LTS, установи)
2. Git            → https://git-scm.com (установи с настройками по умолчанию)

Проверь что установилось (в терминале):
   node --version    → должно показать v22.x.x
   npm --version     → должно показать 10.x.x
   git --version     → должно показать 2.x.x


ШАГ 2. РАСПАКОВАТЬ ПРОЕКТ
------------------------------------------------------------
Распакуй архив в папку, например:
   C:\Projects\mentalos\        (Windows)
   /home/user/mentalos/         (Linux/Mac)

Внутри должны быть папки client/ и server/.


ШАГ 3. ЗАПОЛНИТЬ .env (секретные ключи)
------------------------------------------------------------
1. Скопируй server/.env.example в server/.env
   (или создай файл server/.env вручную)

2. Открой server/.env в блокноте и впиши значения:

   BOT_TOKEN=твой_токен_бота_из_BotFather
   DATABASE_URL=postgres://...   (от Render или локальной PostgreSQL)
   WEBAPP_URL=http://localhost:5173
   PORT=3001

   💡 Значения для BOT_TOKEN и DATABASE_URL спроси у Ивана.
   💡 Ivan, скинь эти два значения защищённым каналом
      (НЕ в групповой чат, НЕ в публичный GitHub!).


ШАГ 4. УСТАНОВИТЬ ЗАВИСИМОСТИ
------------------------------------------------------------
Открой терминал в папке проекта и выполни:

   npm run install:all

Это установит пакеты для корня, client/ и server/.
Займёт 3-7 минут (скачивается ~300 МБ).


ШАГ 5. ПРИМЕНИТЬ МИГРАЦИИ БД (один раз)
------------------------------------------------------------
Если есть DATABASE_URL (PostgreSQL запущена):

   npm run db:migrate

Увидишь: "✅ Миграции применены."
(на сервере это делается автоматически при старте)


ШАГ 6. ЗАПУСТИТЬ (два терминала)
------------------------------------------------------------
Терминал 1 — бэкенд:
   npm run dev:server
   → запустится на http://localhost:3001

Терминал 2 — фронтенд:
   npm run dev:client
   → запустится на http://localhost:5173

Открой в браузере: http://localhost:5173
Вне Telegram данные будут фейковыми (режим разработки).
Чтобы полноценно тестировать — открой MentalOS внутри Telegram.


ЧАСТЫЕ ПРОБЛЕМЫ
------------------------------------------------------------
❌ "npm не является командой"
   → Не установлен Node.js. Установи с nodejs.org.

❌ "Ошибка: DATABASE_URL не задан"
   → Не создал server/.env или забыл вписать DATABASE_URL.

❌ "port 3001 already in use"
   → Порт занят. Поменяй PORT=3002 в server/.env и перезапусти.

❌ Мини-апп не открывается в Telegram
   → Это локальный запуск. Для Telegram нужен деплой на Render
     (см. README.md, раздел "Деплой на Render").
